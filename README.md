# Student Study Habits Analysis

## Project Overview

This project analyzes a university student dataset using Python to explore the factors that may influence academic performance. The analysis focuses on variables such as weekly study hours, scholarship type, reading frequency, exam preparation, and student grades. Using data visualization and exploratory data analysis techniques, the project identifies patterns and relationships within the dataset.

---

## Project Objectives

- Explore and understand the student dataset.
- Perform exploratory data analysis (EDA).
- Visualize relationships between different student attributes and grades.
- Identify trends that may influence academic performance.
- Summarize the findings through data-driven insights.

---

## Dataset

The dataset contains information about **145 university students** with **33 attributes** related to demographics, educational background, study habits, and academic performance.

The dataset includes information such as:

- Student Age
- Gender
- Scholarship Type
- Weekly Study Hours
- Reading Frequency
- Midterm Exam Preparation
- Parents' Education
- Final Grade

## Exploratory Data Analysis

The following steps were performed during the analysis:

- Loaded the dataset using Pandas.
- Explored the dataset using `head()`, `info()`, and `describe()`.
- Checked for missing values.
- Created visualizations to understand different factors affecting student performance.
- Interpreted the results and summarized the findings.

---

## Visualizations

The project includes the following visualizations:

- Grade Distribution
- Weekly Study Hours vs Grade
- Scholarship Type vs Grade
- Reading Frequency vs Grade
- Midterm Exam Preparation vs Grade
- Student Age Distribution
- Correlation Heatmap

---

## Key Findings

- Students with higher weekly study hours generally achieved better grades.
- Reading frequency showed a positive relationship with academic performance.
- Scholarship categories displayed different grade distributions.
- Exam preparation appeared to have an impact on student grades.
- Data visualization helped identify trends and relationships within the dataset.

---

## Conclusion

This project demonstrates how Python can be used to analyze educational datasets through exploratory data analysis and visualization. The analysis provides useful insights into student study habits and academic performance by identifying relationships between different variables.
